# I18n Ally Plus

This repository is a fork of i18n Ally, a VS Code extension that provides useful tools to work with translation files, i18n, etc.

This fork fixes several issues, makes the extension work with Alan's monorepo setup, and has several QoL features (switched to a more modern toolchain, removed telemetry, etc.)

Check the commit log to check what was changed VS the original extension.

**Note:** this fork has been almost entirely vibe-edited via Claude. Don't trust it for mission-critical - just use it like an "oops-maybe-it-breaks" tool, like the tons you probably already have :)

This fork is not currently published.
